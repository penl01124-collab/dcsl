# De Gouden Stap — aanpasbare website

Open `index.html` om de website te bekijken.

## Alles aanpassen
Ga naar `editor.html` of klik onderaan op **Website aanpassen**.
Daar kun je:
- alle teksten aanpassen;
- kleuren aanpassen;
- categorieën toevoegen/verwijderen;
- producten toevoegen/verwijderen;
- eigen afbeeldingen uploaden;
- je wijzigingen opslaan in de browser;
- de inhoud exporteren naar JSON en later weer importeren.

## Online zetten
Upload de volledige map naar bijvoorbeeld GitHub Pages, Netlify of een andere statische hostingdienst.

Let op: de editor bewaart wijzigingen met `localStorage` in de browser. Voor een echte online webshop waarbij wijzigingen voor alle bezoekers centraal worden opgeslagen, is een database/CMS nodig.


## Buy buttons / kooplinks
In `editor.html` heeft ieder product een veld **Koop URL / Buy Button URL**. Plak daar de volledige productlink van je webshop of betaalpagina. Na opslaan verschijnt bij dat product automatisch **Koop nu →** op de collectiepagina. Laat de URL leeg als je voor dat product geen koopknop wilt.
